## Does it hold?

### For Codex: yes [V]
- `agents/openai.yaml` is the Codex adapter. It's generated ("Generated by scripts/sync-adapters.mjs. Do not edit by hand.", `openai.yaml:1`) and sets `policy.allow_implicit_invocation: true` (`openai.yaml:7-8`). That lets Codex start the skill without being asked.
- [A] That this file is read by Codex specifically comes from its name and the `interface`/`policy` shape. Nothing in this repo loads it.

### For Claude Code: yes, by a different route
- [A] Claude Code ignores `openai.yaml`. It decides whether a skill can be invoked automatically from the `SKILL.md` frontmatter: unless `disable-model-invocation: true` is set, the model may invoke the skill whenever its description matches the task. This is Claude Code behaviour, not something in this repo.
- [V] The `qodo-review` frontmatter (`SKILL.md:1-11`) has `name`, `description`, `owner` and `metadata`, and **no `disable-model-invocation`**. A repo-wide grep at `b41eb40` finds `disable-model-invocation` nowhere (`raw/09-grep-vendored-markers.json`).
- [V] The description invites unprompted use: "**Use light background checkpoints while coding**, collect and assess findings with session context…" (`SKILL.md:3`). The body says:
  - "`--fast --async`: light checkpoint" at a coherent milestone (`SKILL.md:31`);
  - "Automatic coding checkpoints always use `--fast`" (`SKILL.md:35`);
  - "Keep at most one automatic checkpoint active per task" (`SKILL.md:50`).
- [V] What gets sent: "`qodo review` sends your diff, new/untracked files and coding-session context to Qodo" (`SKILL.md:17`). The full list is at `SKILL.md:284-289`.
- [V] The prerequisites (`SKILL.md:21-25`) list a CLI, a remote base and attached context, but no user consent to the upload.
- [A] **What still stands in the way in an interactive session:** the upload needs a Bash call to `qodo review`, so Claude Code's permission prompt applies, unless the user has allowlisted `qodo`. I haven't checked this user's settings. The prompt is a safeguard, not consent the skill asks for. A user who approves "run qodo" for a read command could also approve an upload without noticing.
